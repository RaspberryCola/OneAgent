# OneAgent 开源素材清单

这份清单用于发布前统一准备仓库和社区展示素材。

## 必备素材

- `README` 顶部横版 Logo（已具备：`public/oneagent_horizontal.svg`）
- 产品主界面截图（建议至少 2 张）
- 关键流程截图（会话页、权限弹窗、MCP 配置页）
- 仓库社交预览图（Open Graph，1200x630）
- 应用图标（方形，1024x1024，透明背景）

## 推荐规格

### README 内联截图
- 格式：`png`
- 宽度：1600~2200 像素
- 风格：深浅色主题二选一，不混用
- 命名：`docs/assets/screenshot-<scene>.png`

### 演示动图
- 格式：`gif` 或 `mp4`
- 时长：8~20 秒
- 内容：从新建会话到首次响应的完整路径
- 命名：`docs/assets/demo-first-chat.gif`

### Open Graph 封面
- 格式：`png`
- 尺寸：`1200x630`
- 文字建议：`OneAgent` + 一句价值主张
- 命名：`docs/assets/og-cover.png`

## README 建议插图位

1. 标题区下方：产品主界面截图
2. 功能亮点后：权限管理弹窗截图
3. 快速开始后：首次启动引导图

## 发布前检查

- 所有图片链接均使用相对路径
- 没有引用不存在的资源文件
- 图片大小尽量小于 500KB（可读性优先）
- 深色背景图片在 GitHub 页面下可正常辨识
- 对外展示素材不包含敏感路径、密钥或个人信息
